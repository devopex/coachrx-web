#### 12/8/4 Wave Load Program Breakdown

```
The 12/8/4 Wave Load Program is a wave load program that fits well in an accumulation phase. This is a 3-day Full Body Resistance (FBR) split with 1 wave load, compound, priority exercise per day. 

Wave loading is a beneficial method to take advantage of the post activation activation (PAP) phenomenon. PAP is a temporary enhancement of muscle contractile performance that can occur following a high-intensity exercise. In practice, repeating the 12/8/4 the second wave will allow for increased loads relative to the first.
```

Daily Plan

- ```
  Monday: Squat, bend, push (horizontal), calves, pull (elbow flexion)
  ```
- ```
  Wednesday: Push (horizontal), squat, pull (horizontal), bend, push (elbow extension)
  ```
- ```
  Friday: Bend, lunge, pull (vertical), squat, pull (scaps)
  ```

Who is Wave Loading For?

```
Training Age = Intermediate - Advanced
Wave loading is appropriate for more advanced clients who want to increase their strength and who have experience lifting heavier loads. It’s essential that they have gained motor control in each movement pattern and are not limited by movement efficiency. It’s a training tool that can help overcome plateaus by helping prep the nervous system to fire more efficiently.
```
