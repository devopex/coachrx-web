Creating great programming is one thing - but turning it into a profitable product that's easy to sell and manage is another challenge entirely. Today, I want to show you how CoachRx makes it simple to package and sell your programming without getting stuck in technical details.

### **What It Is:**

A built-in program creation and sales system that lets you create, sell, and manage both standard and live programming templates with automated sales pages and client management features.

### **How to Use It:**

#### Create Your Program Template

**Standard Programs:**

- Design programs with specific durations
- All clients start at day one
- Enable sync program changes for easy updates
- Perfect for specific training blocks or challenges

**Live Programs:**

- Create date-based programming
- Clients start on current calendar date
- Ideal for ongoing WOD-style programs
- Great for group programming
![](/images/content/cdc473c8cb-1.webp)

**Set Up Your Sales Page**

- Use auto-generated unique URL
- Add program banners and videos
- Include coach information and credentials
- Configure trial periods if desired
- Set up payment plans (monthly/yearly options)
![](/images/content/7154264842-2.webp)

**Configure Client Experience**

- Set commenting permissions
- Enable/disable video uploads
- Control workout visibility
- Manage client communication access
![](/images/content/2328d58f43-3.webp)
