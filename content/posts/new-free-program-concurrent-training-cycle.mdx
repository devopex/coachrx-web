#### Concurrent Training Cycle Breakdown

```
This 6-week program uses concurrent training principles to blend resistance, aerobic, and anaerobics into days and across weeks of training, while minimizing interference between the energy systems.
```

```
You’ll see the following principles play out inside this program:
```

```
1) Intra-session ordering: Do not perform Pain work before Sustain or Gain 
```

```
2) Intra-week ordering: Allow for a recovery day after Pain work 
```

```
3) Train the priority energy system first intra-session 
```

```
4) Use appropriate efforts in Sustain work, especially when performing Gain or Pain after 
```

*G= Gain or resistance training*

*P= Pain or anaerobic training*

*S= Sustain or aerobic training*

Daily Plan

- ```
  Monday: G+S, Squat, Pull (v), bend, push (h), MAP 6 (m)
  ```
- ```
  Tuesday: S+G, MAP 6 (mc), lunge, pull (h)
  ```
- ```
  Wednesday: rest
  ```
- ```
  Thursday: G, Lunge, Push (h), bend, pull, core, pull (s)
  ```
- ```
  Friday: G+S, Bend, Pull (h), squat, push (v), MAP 6 (mc)
  ```
- ```
  Saturday: S+P, MAP 10 (m), AnLP 2 
  ```
- ```
  Sunday: rest
  ```

Who is Concurrent Training For?

```
Training Age = Intermediate - Advanced
```

```
This concurrent training cycle is designed for an intermediate to advanced individual who wants to challenge all three energy systems. Concurrent training that includes Pain is not recommended for beginner trainees who are not yet strong enough to express it and don’t have the appropriate base built to challenge the anaerobic energy system. Beginners can still perform concurrent training that includes Gain and Sustain only. It is important to keep in mind that while you can see improvement in all three energy systems, it’s impossible to maximize them all concurrently.
```
