#### Program Design Pro Tip: **Meal Plan by AI**

```
When it comes to achieving fitness goals, nutrition is a cornerstone. Tailoring meal plans to your clients' specific needs can be a time-consuming task, but with the help of AI, it becomes efficient and personalized.
```

***Use a client’s target macros to build an AI-powered meal plan based on number of meals and personal preferences.***

Steps to Use

1. ```
   Determine Macronutrient Goals:
   ```

   ```
   Start by understanding your client's macronutrient goals. This forms the foundation of their personalized meal plan.
   ```
2. ```
   Meal Frequency:
   ```

   ```
   Identify how many meals per day your client intends to consume. This aspect of meal planning is crucial for ensuring they meet their nutritional requirements.
   ```
3. ```
   Extra Context:
   ```

   ```
   Consider any additional context that could make the meal plan even more personalized. This might include dietary preferences, food sensitivities, or any specific culinary likes and dislikes.
   ```
4. ```
   AI-Powered Recommendations:
   ```

   ```
   Now, use the AI-generated recommendations as a starting point for constructing a day of eating that aligns with your client's unique requirements. These recommendations not only suggest meal options but also provide the caloric and macronutrient breakdown for each meal.
   ```

The Prompt

*Based on my client’s [macronutrient goals], [number of meals] they intend on eating per day, and [extra context] to build a day of eating based on each consideration.*

*Also, ensure to add the caloric and macronutrient breakdown of each meal.*

*Macronutrient Goals = [protein: carbohydrate: fat: ]*

*Number of Meals Per Day = [ ]*

*Extra Context = [ ]*
