#### **HOW TO IMPORT EXISTING CLIENTS TO COACHRX**

```
Importing a book of existing clients is as easy as heading to the Import Clients section in your settings on CoachRx and selecting mass import. 
```

```
Note: If you’re importing from TrueCoach, there’s a simple five step process laid out for you, and if you’re importing from scratch, all you have to do is download a spreadsheet that we also provide you with, upload the file and then import. 
```

```
After this has been done, your clients will all receive a welcome email and invite to CoachRx, which asks them to download and sign up for CoachRx with a username and password.
```

```
We offer complementary transition assistance to import your client list, exercise library and more. Start your free trial and connect with your Coach Success Manager to get underway.  Learn more about Transition Assistance here.
```

#### **HOW TO ADD NEW CLIENTS**

```
Adding new clients is even easier on CoachRx.
```

```
Simply hit add client and then begin filing out their basic information: first name, last name, sex, their time zone, as well as whether they prefer imperial or metric units in their exercise prescriptions (the system will convert for you to match the client’s preference). Finally, if you’re going to be using the payroll function in the Business Suite on CoachRx, you’ll also have the option to select the commission type, which will make doing payroll a whole lot easier. 
```

```
Once again, the client will then receive an email invite, as well as all the instructions they need to download the mobile app and get started on CoachRx. These instructions will also allow them to add things like the equipment they have access to, their schedule, along with other pertinent information that will make designing their program more efficient for you.
```

```
Note: CoachRx also houses intake forms for new clients to fill out prior to their initial consultation. You’re free to use the one CoachRx provides, or you can create and upload your own file.
```
