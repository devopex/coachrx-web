#### German Volume Training Program Breakdown

```
This 6-week progression uses a Full Body German Volume Training method, performed three times a week. 
```

```
GVT is an advanced hypertrophy protocol using high volume and low rest periods. Popularized by German weightlifters in their off-season in the 1970s, its intention is to increase size through volume & intensity. 
```

Daily Plan

- ```
  Monday: Squat, Pull (horizontal), bend, pull (elbow flexion)
  ```
- ```
  Wednesday: Bend, Push (vertical), lunge, pull (elbow flexion)
  ```
- ```
  Friday: Squat, Push (horizontal), bend, pull (scap)
  ```

Pros of GVT

- ```
  Large stimulus
  ```
- ```
  Get folks over the hump
  ```
- ```
  Creates discipline and patience
  ```
- ```
  Progressive overloading through volume, intensity & exposure
  ```

Cons of GVT

- ```
  Recovery. Huge strain on the nervous system, tendons, ligaments and joints
  ```
- ```
  Lack of variation (both a pro and con)
  ```
- ```
  Time consuming
  ```

Who is GVT For? 

```
Training Age = Advanced
```

```
Keep the above pros and cons in mind when deciding whether or not to assign this program to your clients. GVT is for advanced clients who want to gain muscle and are able to put a high priority on recovery and quality nutrition. It should be used sparingly during a tough phase (i.e. don’t program back to back GVT cycles!).
```
