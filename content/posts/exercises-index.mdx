#### Program Design Pro Tip: **Exercises Index**

```
A well-structured and organized Exercises Index forms the bedrock of your coaching systems, drastically reducing onboarding and program design time. OPEX has provided 1800+ preloaded, high-quality exercises to get you started, but you can also add your own. 

The default exercises are organized by movement patterns: bend, squat, lunge, push, pull, core, cyclical, and mobility, so you can search the Index to pull up movement inspiration for each pattern.
```

Adding Exercises to the Index

```
There are two ways you can add exercises to your Index.
```

![](/images/content/b8c3fde99d-screenshot-2023-08-17-at-1-35-56-pm.webp)

Option 1: From the Index, click the Add Exercise button, add a YouTube or Vimeo link, and fill out all relevant information.

![](/images/content/d2f539c26f-screenshot-2023-08-17-at-1-36-52-pm.webp)

Option 2: You can also “quick add” an exercise you realize you’re missing while designing a workout.

Type the name of the exercise and then click the +camera icon to add a link. If you’d like to fill out the remaining details, do so through the Index.

Sharing Exercise Videos with Your Clients

```
When you design a workout and start typing to add an exercise, you’ll see a dropdown menu of exercise demos that live in the Index. Simply click to ensure the video links to the exercise you’re prescribing. Your client will receive a short and clear demo of the movement they’re about to perform in the mobile app. 
```

```
You can also link exercise demos when prescribing warm-ups, cooldowns, and mixed modal pieces. Just type the exercise name in the “add demo video” field and select the video from the list. 
```

```
Bonus: when you build warm-ups, cooldowns, and programs in your Index, you can add exercise videos there. These will automatically populate anytime you assign these default elements. 
```
