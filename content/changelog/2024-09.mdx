We’re excited to share the latest updates and enhancements to both the CoachRx Web App and Mobile App. These improvements are designed to make your coaching experience more efficient and enjoyable.

Here’s What’s New in August:

Web App Enhancements:

- **Enhanced Media Viewing :** Images in comments & messages can now be clicked to view at a larger size. Improved Time Tracking : Hover over timestamps in comments & messages to see the exact time. Streamlined Communication : Reminders have been converted into scheduled messages for better management. Extended Workout Descriptions : Workout title character limit increased from 50 to 75 characters. Advanced Invoice Management : Added Void & Uncollectible tabs for more comprehensive invoice tracking. Fixes & Refinements Data Preservation : Resolved an issue where adding Loom videos to new workouts erased some data fields. Consistent Video Display : Fixed inconsistent demo video ordering in the coach mobile app. Social Media Integration : Corrected external links on social media storefronts. Time Zone Compatibility : Addressed short-term plan end dates issues with differing time zones. Tag Consistency : Fixed short-term plan tags showing inconsistently on Sundays. Lifestyle Prescription Duplication : Resolved a bug preventing the duplication of lifestyle prescriptions. Payment Data Accuracy : Corrected inconsistencies in payment data after deleting or transferring clients. Reporting Accuracy : Fixed a bug affecting payment reporting for custom date ranges. Workout Editing Stability : Resolved an issue where warmups/cooldowns disappeared when editing workouts. Check-in Consistency : Corrected the order of weekly check-in questions. Performance Optimization : Improved loading speed of the Coaches page.
