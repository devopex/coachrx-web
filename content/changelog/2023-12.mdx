### WEB & MOBILE APP REFINEMENTS

What’s New:

- **Client Calendar Improvements:** We’ve added an “undo feature” to the client calendar so that you can easily undo a change to a clients program. We’ve also made it possible to see all workouts on a given day displayed even while editing one of the workouts.

- **New Program added to the programs library:** Longevity Split (7X Week).

Refinement, Bug Fix

Improved loading state visualization. Improved ordering of weekly check-in questions. Improved INF/NaN metrics display on team page for new accounts. Improved visualization of contracts/waivers table. Improved visibility of input text in lifestyle comments when in light mode. Touchpoints stats now reset at the end of the day each Sunday.

- Improved loading state visualization.

- Improved ordering of weekly check-in questions.

- Improved INF/NaN metrics display on team page for new accounts.

- Improved visualization of contracts/waivers table.

- Improved visibility of input text in lifestyle comments when in light mode.
