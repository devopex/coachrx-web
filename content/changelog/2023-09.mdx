### WEB APP REFINEMENTS

Refinement, Bug Fix

- **Programs:** Hotkeys added to programs calendar. Improved loading state for programs index. Improved function of dragging workouts and copy/paste. Fixed a bug that was causing performance issues when duplicating programs. Calendar Updates: Fixed calendar bug so only one workout is editable at once and workout autosaves after jumping to another workout. Updated so missed workouts automatically update to pending when dragged to future date. Touchpoints: Now displaying individual touchpoints for each client. Planning & Periodization Bug: Fixed bug that caused short-term plans to overlap when editing existing plans. Loom Bug: Fixed bug causing Loom videos to not save when editing a workout. Lifestyle Program Bug: Fixed bug when assigning a lifestyle program template from the Index that caused re-ordering of prescriptions. Client Profile Update: Added editable height, weight, and age to the client profile from the client calendar. Organization Updates: Added ability to add more than 501 clients to an account. Fixed bug causing “invite pending” to display after client had accepted the invitation. Fixed a bug preventing new coaches from being added for some users. Fixed bug preventing some daily Rx emails from sending.
